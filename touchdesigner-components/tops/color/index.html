Color

TD COMPs / TOPs / 2023 – Present

This category of components focuses on translating, interpreting, and standardizing color data within TouchDesigner. While images are fundamentally numerical, their meaning is often tied to color spaces, encoding methods, and external formats. These components provide explicit control over how color is represented, converted, and imported into procedural workflows.

To maintain clarity and scalability, this collection is divided into subcategories:

  1. Converters:

    These components provide tools for translating between color spaces and encoding formats, converting input TOPs to and from RGB and other standard color models. By making these transformations explicit, they enable more predictable color behavior across compositing, shading, and image processing workflows.


  2. Importers:

    These components handle the ingestion of external color data, converting formats into TouchDesigner‐compatible RGB values. This allows color palettes and externally defined color systems to be integrated directly into procedural environments.

Together, these Color components provide a consistent framework for working with color in both technical and creative contexts.
